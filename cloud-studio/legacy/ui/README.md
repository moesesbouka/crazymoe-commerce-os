# Existing office Studio UI

These files preserve the current office Studio as the starting point for cloud
adaptation. They still call office API routes and are not a deployed cloud UI.
The header now includes the owner-requested direct Facebook create-item link;
it opens a new tab and performs no publication. The office HTML was backed up
and hash-checked before applying that change.

Do not serve these files as a complete cloud Studio until transport, login,
revision-bound approval, private photos, uploads, and handoff have been adapted
and tested. Manufacturer image selections require migrated content, not just
URLs. Saved fields and generated candidates must remain distinct in the editor.

Browser rendering was attempted in the isolated workspace but the browser
binary download failed. Source syntax checks do not establish browser success.
